# AyerAquí

PWA para mirar cómo era un lugar: abre la cámara, usa tu ubicación y superpone fotos históricas de Wikimedia Commons por década.

## Uso local

```bash
npm install
npm run dev
```

La cámara y el GPS requieren HTTPS (o `localhost`).

## Build

```bash
npm run build
npm run preview
```
