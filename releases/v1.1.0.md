# AyerAquí v1.1.0 — features

Fecha de release: 2026-08-13  
URL de deployment: https://databrainsco.github.io/ayeraqui/  
Repo: https://github.com/databrainsco/ayeraqui

## Qué incluye esta versión

### Experiencia cámara
- Vista en vivo con cámara trasera (cuando el dispositivo lo permite)
- Overlay de foto histórica sobrepuesta a la cámara (mezcla por opacidad)
- Modo **Sobreponer** (slider Ahora ↔ Antes) y modo **Alinear** (pan + zoom)
- Al abrir la cámara **no hay lugar/foto preseleccionada**; el usuario elige una década

### Ubicación y fotos
- Geolocalización GPS de alta precisión
- Búsqueda de fotos históricas cercanas en **Wikimedia Commons** por coordenadas (global, no solo México)
- Radios de búsqueda: 50 / 90 / 150 / 250 / 400 m
- Foto curada: Rectoría UNAM — mural de Siqueiros (1950s), con ficha técnica
- Las fotos curadas se pueden abrir desde el mapa aunque no estés en el sitio (vista previa + distancia)

### Mapa de lugares
- Mapa interactivo (Leaflet) con:
  - puntos **curados** (ámbar)
  - **hotspots Commons** recomendados (verde)
  - fotos Commons detectadas cerca del usuario
- Lista de lugares con distancia cuando hay GPS
- Acciones: actualizar ubicación, ver foto curada (Rectoría)

### UI / PWA
- App instalable (manifest + service worker)
- Interfaz en español
- Ficha técnica bajo demanda (**Ver ficha** / **Ocultar ficha**), sin auto-apertura
- Versión visible en el pie del inicio (`v1.1.0`)
- Sin foto histórica como fondo del home

### CI/CD
- Deploy automático a GitHub Pages en push a `main`
- Artefacto de release versionado con `dist/`, features y metadatos del deployment
